    左边输入一个问题，点「开始研究」。它会先规划检索词，再逐篇读原文，最后把读到的内容写成简报。

    现在默认走「回放快照」：用三份固定的示例网页跑完整条链路，不联网、不需要 key。想接真实互联网，在 .env 里填 TAVILY_API_KEY 与模型 key，再选「在线检索」。

    这个页面在做什么

    你给出一个问题，它做四件事：

    1. 规划检索词：把问题拆成几条搜索请求。
    2. 读原文：打开搜索结果里的页面，存下正文快照。
    3. 写结论：每条结论必须引用正文里的原句，引用对不上原文的结论会被丢掉。
    4. 自查：检查引用是否登记、来源是否在时间窗口内、转载是否被当成独立验证。

    右侧每一步都能看到。点「取消」会停在当前阶段，不生成报告。

    「发布方说法 / 部分支撑」这类标注不是装饰：它在告诉你这条结论只有一家之言，还没有第二方确认。
